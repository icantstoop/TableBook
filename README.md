# TableBook

REST API для бронирования столиков в ресторанах. Учебный проект на Spring Boot.

## Что умеет

- Рестораны и столики: создать, посмотреть, изменить, удалить
- Регистрация пользователей
- Бронирование столика на дату и время. Если столик в это время занят, вернётся ошибка

## Технологии

Java 17, Spring Boot, Spring Data JPA, PostgreSQL, Flyway, Lombok, Maven


## Основные эндпоинты


 GET, POST - `/api/v1/restaurants` - список и создание ресторанов 
 GET, POST - `/api/v1/tables` - список и создание столиков 
 POST - `/api/v1/auth/register` - регистрация 
 POST - `/api/v1/bookings` - создать бронь 

Пример брони:

```json
{
  "tableId": 1,
  "bookingDate": "2026-10-10",
  "startTime": "18:00:00",
  "endTime": "19:00:00",
  "guestsCount": 2,
  "userId": 1
}
```

## Ограничения

Проект учебный: нет авторизации, пароли хранятся без хэширования.
